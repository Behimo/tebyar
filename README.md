# طبیار

شبکه اجتماعی پزشکان، رزیدنت‌ها و دانشجویان پزشکی. بک‌اند لاراول و یک رابط راست‌چین که هم وب/PWA است و هم با Capacitor به اندروید می‌رود.

## اجرا

```bash
cd apps/api
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

در ترمینال دیگر:

```bash
cd apps/web
npm install
npm run dev
```

وب روی `http://127.0.0.1:5173` و API روی `http://127.0.0.1:8000`. در حالت محلی کد ورود در صفحه OTP نشان داده می‌شود و در لاگ لاراول هم ثبت می‌شود. برای پیامک واقعی `SMS_DRIVER=kavenegar` و `KAVENEGAR_API_KEY` را بگذارید.

## دسترسی‌ها (محلی)

| سرویس | آدرس |
|--------|------|
| اپ وب | http://127.0.0.1:5173 |
| API | http://127.0.0.1:8000 |
| **پنل Filament (ادمین)** | **http://127.0.0.1:8000/admin** |

ورود پنل با **ایمیل + رمز** (نه OTP). همهٔ کاربران دمو رمزشان `password` است.

| نقش | ایمیل | رمز | توضیح |
|-----|-------|-----|--------|
| ادمین | `admin@tebyar.test` | `password` | تأیید هویت، کاربران، گزارش‌ها، آگهی‌ها |
| پشتیبان | `support@tebyar.test` | `password` | تیکت پشتیبانی |
| ناظر | `moderator@tebyar.test` | `password` | گزارش‌ها و محتوا |

### ورود اپ (OTP)

شماره موبایل را در `/login` بزنید؛ در حالت `SMS_DRIVER=log` کد پنج‌رقمی روی صفحهٔ OTP نشان داده می‌شود.

| شماره | عضو | نقش |
|-------|-----|-----|
| `09121000011` | دکتر محمد رضایی | متخصص قلب — **اکانت پیشنهادی دمو** |
| `09121000012` | دکتر سارا کریمی | متخصص پوست |
| `09121000013` | دکتر علی احمدی | متخصص داخلی |
| `09121000014` | دکتر رضا نوری | دستیار تخصصی |
| `09121000015` | نیلوفر محمدی | دانشجو (دسترسی محدود) |
| `09121000016` | کسری مرادی | اینترن (دسترسی محدود) |
| `09121000017` | دکتر مریم صادقی | داروساز |
| `09121000018` | زهرا حسینی | پرستار |
| `09121000019` | دکتر امید کاظمی | دامپزشک |
| `09121000020` | سارینا احمدی | عموم مردم (دسترسی محدود) |
| `09121000031` | مرکز درمانی تهران | کارفرما |

دادهٔ دمو (پست، انجمن، کیس، پیام، آگهی) با `php artisan migrate:fresh --seed` ساخته می‌شود.

گفتگوی زنده با Laravel Reverb سیم‌کشی شده است. بدون اجرای `php artisan reverb:start` و `php artisan queue:work` هم گفتگو با به‌روزرسانی چندثانیه‌ای کار می‌کند. پوش اندروید فقط وقتی `FCM_SERVER_KEY` باشد ارسال می‌شود.

احراز نظام پزشکی دستی است و در صف ادمین انجام می‌شود.

## اندروید

```bash
cd apps/web
npm run build
npx cap sync android
```

ساخت APK به Android SDK نیاز دارد. اگر SDK نصب نباشد، پروژه اندروید در مخزن می‌ماند و بیلد محلی انجام نمی‌شود.
